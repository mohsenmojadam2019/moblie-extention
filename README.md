# Responsive Mobile Studio 📱

افزونه Chrome برای بررسی **ریسپانسیو** سایت روی گوشی‌ها و تبلت‌های مختلف، به همراه شبیه‌سازی در تب واقعی مرورگر.

## امکانات

- مشاهده چند اندازه موبایل هم‌زمان با تصویر هر تب واقعی Chrome و امکان کلیک، پیمایش و تایپ
- پیش‌فرض‌های iPhone، Galaxy، Pixel، تبلت و دسکتاپ
- تعریف ابعاد دلخواه و تغییر مقیاس ۵۰ تا ۱۰۰ درصد
- چرخش افقی/عمودی، بارگذاری مجدد و مدیریت لیست دستگاه‌ها
- بازکردن وب‌سایت در **تب واقعی Chrome** با Device Metrics و Touch Emulation
- گرفتن اسکرین‌شات PNG از تب شبیه‌سازی‌شده
- بررسی عناصر مشکوک به خروج افقی از viewport (Horizontal Overflow Audit)
- ذخیره آخرین URL و دستگاه‌های انتخاب‌شده در مرورگر
- پشتیبانی از HTTP/HTTPS و سایت‌های لوکال مانند http://localhost:3000

## نصب روی Chrome

۱. مخزن را به صورت ZIP از GitHub دانلود و Extract کنید یا با git clone دریافت کنید.

۲. آدرس زیر را در Chrome وارد کنید:

    chrome://extensions

۳. گزینه **Developer mode** را روشن کنید.

۴. روی **Load unpacked** کلیک کنید و پوشه پروژه (جایی که فایل manifest.json قرار دارد) را انتخاب کنید.

۵. افزونه Mobile Studio را از منوی Extensions به نوار ابزار Pin کنید.

## استفاده

۱. روی آیکون افزونه بزنید، URL سایت را وارد کنید و یکی از گوشی‌ها را انتخاب کنید.
۲. با گزینه «نمایش چند گوشی کنار هم» وارد Studio شوید؛ مدل‌های دلخواه را از سمت راست فعال کنید.
۳. در Studio، برای هر دستگاه یک تب پس‌زمینه واقعی Chrome ساخته می‌شود و تصویر آن در کارت قرار می‌گیرد. روی تصویر کلیک کنید، پیمایش کنید یا متن تایپ کنید. با «تب واقعی» همان تب باز می‌شود.
۴. در تب واقعی، دوباره آیکون افزونه را بزنید: می‌توانید دستگاه را عوض کنید، صفحه را بچرخانید، عکس PNG ذخیره کنید، بیرون‌زدگی افقی را بررسی کنید یا حالت شبیه‌سازی را خاموش کنید.

## محدودیت‌های فنی مهم

- پیش‌نمایش چندتایی **دیگر از iframe استفاده نمی‌کند**. تصاویر از تب‌های واقعی Chrome گرفته می‌شوند؛ سیاست‌های امنیتی وب‌سایت تغییر نمی‌کنند. این نمای بازپخش‌شونده عکس است، نه DOM تعبیه‌شده؛ ممکن است برخی تعاملات پیچیده کندتر باشند.
- برای شبیه‌سازی دقیق‌تر از API رسمی **chrome.debugger** و Chrome DevTools Protocol استفاده می‌شود؛ مرورگر هشدار «این افزونه در حال اشکال‌زدایی است» را نشان می‌دهد.
- بازکردن DevTools روی تب شبیه‌سازی‌شده ممکن است جلسه Debugger افزونه را قطع کند. اگر این اتفاق افتاد دوباره روی «شبیه‌سازی روی تب فعلی» بزنید.
- نمایشگر دستگاه (CSS viewport / DPR / touch) شبیه‌سازی می‌شود؛ این افزونه **شبیه‌ساز کامل سخت‌افزار یا موتور Safari در iOS نیست**. رفتار Safari باید روی دستگاه واقعی یا سرویس تست مخصوص بررسی شود.
- پیش‌نمایش‌های هم‌زمان، هر کدام یک تب پس‌زمینه باز می‌کنند که همراه با بسته‌شدن صفحه Studio بسته می‌شوند. برای استفادهٔ کاملاً روان از یک دستگاه، گزینهٔ «تب واقعی» را بزنید.
- گزارش Overflow فقط عناصر DOM سند اصلی را بررسی می‌کند؛ iframeهای cross-origin و تمام خطاهای ظاهری/تعاملی را پوشش نمی‌دهد.
- این افزونه فقط نمای سایت را بررسی می‌کند؛ **کد وب‌سایت، سرور یا دیتابیس را تغییر نمی‌دهد**.

## دسترسی‌ها

| Permission | کاربرد |
|---|---|
| tabs | پیدا کردن تب فعال و بازکردن تب تست |
| storage | نگهداری تنظیمات محلی |
| debugger | شبیه‌سازی اندازه صفحه، لمس، اسکرین‌شات و بررسی Overflow |
| downloads | ذخیره اسکرین‌شات PNG |

هیچ سرویس خارجی، سیستم ردیابی یا وابستگی npm برای اجرای افزونه استفاده نشده است. تمامی فایل‌ها محلی هستند.

## ساختار پروژه

- manifest.json — تنظیمات افزونه Manifest V3
- background.js — مدیریت تب‌ها و Chrome DevTools Protocol
- devices.js — فهرست مدل‌ها و اعتبارسنجی URL
- popup.html / popup.js — کنترل‌های سریع افزونه
- studio.html / studio.css / studio.js — محیط پیش‌نمایش چند دستگاه
- icons/ — آیکون‌های PNG افزونه

## بررسی دستی قبل از انتشار عمومی

- نصب به صورت Unpacked و بررسی بخش Errors در chrome://extensions
- نمایش چندتایی روی سایتی که iframe را ممنوع می‌کند (مثلاً digizargar.com)
- تست «تب واقعی» روی یک URL عادی و یک localhost؛ تست کلیک، پیمایش و تایپ داخل تصویر
- تست تغییر دستگاه، افقی/عمودی، اسکرین‌شات و توقف شبیه‌سازی
- تست صفحه‌ای با overflow و صفحه‌ای بدون overflow
- بررسی رفتار سایت‌هایی که iframe را مسدود می‌کنند
